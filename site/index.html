Pipeline plan · v0 · pre-benchmark

Script in.
Vertical video out. Human approves.

A semi-automated pipeline that turns a text script into a 60–90s narrated gameplay video for Shorts/Reels: local TTS, forced-alignment karaoke subtitles, LLM-placed meme overlays, generated FFmpeg filtergraphs, an automated validation gate, and a human in the loop before anything ships.

01

The pipeline

Every stage reads files and writes files. Any stage can be re-run without redoing the others. The LLM never sees video; the renderer never makes decisions.

STAGE 1doc 01

Intake

Normalize text before TTS ($5 → five dollars). Word-count lint: 150–230 words ≈ 60–90s.

STAGE 2doc 02

Voice

Kokoro 82M, local CPU, Apache-2.0. Voice picked by ear test — it is the channel identity.

STAGE 3doc 03

Align

WhisperX forced alignment vs the normalized script → words.json with per-word confidence.

STAGE 4doc 05

Place

LLM proposes meme/PNG overlays with word-anchored timings. Schema-probe + one repair retry. Human approves in chat.

STAGE 5doc 07

Timeline

timeline.json — the single source of truth. Layout zones, fixed genre effects pack, karaoke ASS.

STAGE 6doc 08

Render

One generated FFmpeg filtergraph. 1080×1920, libx264 + AAC. Segment + draft modes for fast iteration.

STAGE 7doc 11

Validate

ffprobe format checks + black/freeze/silence detect + −14 LUFS loudness. Auto-reject, max 3 re-renders.

STAGE 8doc 12

Approve

Human eyeballs the draft at 1×. Mechanical errors must already be green — taste is the human's job.

STAGE 9doc 13

Publish

Manual upload in v1. LLM drafts title/description/hashtags; human pastes and edits.

03

Invariants

Rules no stage may break. Most are statically checkable before render.

timeline.json is truth

The FFmpeg generator consumes it and nothing else. Approval edits the file, never the render code.

Transcript == audio by construction

Normalize first; TTS and alignment both consume the normalized text. A mismatch means a missing lexicon entry.

Word anchors, not seconds

Placements reference phrases, resolved via words.json. Voice regeneration re-resolves everything.

Safe zones are absolute

Nothing in the bottom 300px. Subtitle band is reserved. One active overlay per zone.

30ms fades at every cut

Clicks at seams are the most audible amateur signal in the genre.

Stages are files in, files out

Idempotent, resumable, inspectable. LLM output is frozen at approval — never auto-regenerated.

04

Residual risks

What the design rounds couldn't close, ordered by blast radius.

1

Karaoke timing stack: \kf × WhisperX tightest tolerance

The selected sweep style exposes ±50ms alignment errors, and the confidence gate is the only automated defense.

Generator supports \k instant swap from day one — one flag, zero timing-logic changes. Benchmark slice is judged by eye for exactly this.
2

Vision support on the LLM endpoint

Asset auto-tagging requires image inputs; many /v1 relays don't accept them. Unproven.

Probe on day one alongside json_schema. Fallback: hand-tag the seed pack, defer auto-tagging.
3

Kokoro genre fit

Right size, right license — but narration energy is a listening test, not a spec.

Three-sample ear test before the first real video; voice choice is isolated from all downstream stages.
4

Single external dependency

LLM endpoint down = no placements = pipeline halt. Accepted consciously.

Failure halts one video, corrupts nothing; stage-cached state resumes cleanly when it returns.
5

Channel-level platform risk

Dozens of structurally identical videos is what inauthentic-content enforcement pattern-matches — regardless of clean footage rights.

Vary voice, game, and effect cadence (decision 28). Keep approval real — rubber-stamping kills channels.
05

The gate before the build

Every commitment above assumes the target box can run this at acceptable speed. Currently unmeasured.

10-second end-to-end prototype pending re-confirm

One real script excerpt through the full chain — normalize → Kokoro → WhisperX → 3 hand-written placements → timeline.json → generated filtergraph (crop + karaoke + overlay pop-in + zoom-punch + ducked music) → validation gate. Every stage timed. Then extrapolate.

StageWall timeScaling note
TTS — Kokoro, CPU—~linear with script length
Alignment — WhisperX int8—model load amortizes per batch
ASS generation—expected negligible
Render — libx264 preset slow—the number most likely to fail
Validation—~1× playback duration
Total / video—gate: < 10 min for 60–90s

Pass criteria

  • Total < 10 min for a 60–90s video (extrapolated)
  • Karaoke timing acceptable by eye on the slice
  • Flagged-word ratio < 10%

If it fails

  • Render slow → preset medium → draft canvas → hardware question
  • Align slow → smaller whisper model → alignment-only path
  • Voice fails ear test → voice decision reopens; downstream unaffected
